## 7. Limitations (real)

- **Synthetic content:** the picture is a generated test pattern with noise and the sound a sine tone — a real, valid H.264/AAC MP4 accepted by the media rule, but not camera footage.
- **Local transport:** the parts travel from a container to MinIO inside the same Docker VM; the throughput (≈ 1.3 GiB/s) reflects local disk and virtual networking, not an Internet client.
- **Memory sampling:** RSS sampled once per second; the 10 GiB upload took about 8 s, so the upload window has about 8 samples (all within 175–196 MiB).
- **Process under test:** the API and worker measured are the test instances started by the script (same compiled code, test identities and test resources, as the plan requires), not the operational `nestjs-api`/`worker` services.
- **Interruption:** simulated by destroying the in-flight `PUT` requests (client crash); a network outage of the storage itself was not part of this run (covered by the regression suites).
- **Lint scope:** the script lives in `scripts/`, outside the project's ESLint scope (`{src,apps,libs,test}`); it is type-checked by `tsc --noEmit`.
